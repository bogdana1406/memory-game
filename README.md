# Memory Game

Memory Game — браузерная игра на поиск пар карточек, созданная в рамках
задания RS School. Тема карточек — технологии экосистемы JavaScript.

## Деплой

[Открыть Memory Game](https://bogdana1406.github.io/memory-game/)

## Возможности

- игровое поле из 16 перемешанных карточек;
- подсчёт ходов и найденных пар;
- блокировка поля на время показа несовпавших карточек;
- перезапуск игры без перезагрузки страницы;
- таблица 10 лучших результатов с сохранением в `localStorage`;
- адаптивный интерфейс и управление с клавиатуры.

## Технологии

- HTML;
- CSS;
- JavaScript (ES modules).

Интерфейс приложения полностью создаётся с помощью JavaScript и
`document.createElement`.

Пакет `http-server` используется только для локального запуска приложения и
раздачи его статических файлов. Он не участвует в создании интерфейса или
игровой логике.

## Локальный запуск

Для запуска потребуются [Node.js](https://nodejs.org/) и npm.

1. Клонируйте репозиторий, перейдите в его папку и переключитесь на ветку
   `memory-game`:

   ```bash
   git checkout memory-game
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите приложение:

   ```bash
   npm start
   ```

4. Откройте в браузере [http://localhost:8080](http://localhost:8080).
